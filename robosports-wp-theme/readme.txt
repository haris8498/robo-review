A futuristic B2B wholesale theme for Robosports with WooCommerce and Elementor support.

== Description ==

Robosports is a cutting-edge WordPress theme designed specifically for B2B wholesale businesses. With its futuristic design, cyber-inspired aesthetics, and robust functionality, it's perfect for companies in sportswear, industrial workwear, and specialized equipment sectors.

= Features =

* Fully responsive design
* WooCommerce integration
* Elementor compatibility
* Custom post types for products
* Advanced hero slider
* Product carousel
* Client testimonials section
* Trust badges and statistics
* Mobile-first approach
* SEO optimized
* Translation ready
* Accessibility compliant
* Performance optimized

= Customization =

The theme includes a comprehensive customizer with options for:
* Hero section content
* Contact information
* Color schemes
* Typography settings
* Layout options

= Support =

For support and documentation, please visit our website or contact our support team.

== Installation ==

1. Upload the theme files to the `/wp-content/themes/robosports` directory, or install the theme through the WordPress themes screen directly.
2. Activate the theme through the 'Appearance > Themes' screen in WordPress.
3. Use the Appearance > Customize screen to configure the theme options.

== Frequently Asked Questions ==

= Does this theme support WooCommerce? =

Yes, the theme is fully compatible with WooCommerce and includes custom styling for all WooCommerce pages.

= Is the theme compatible with Elementor? =

Yes, the theme works seamlessly with Elementor page builder.

= Can I customize the colors? =

Yes, you can customize colors through the WordPress Customizer or by modifying the CSS variables in the theme files.
